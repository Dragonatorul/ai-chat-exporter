Basic Text Formatting

You can emphasize text in several ways:

  • Bold text using double asterisks or underscores: **bold** or __bold__.
  • Italic text with single asterisks or underscores: *italic* or _italic_.
  • Bold and italic combined: ***bold italic***.
  • Strikethrough with tildes: strikethrough (~~strikethrough~~).
  • Underline isn't native to Markdown, but some renderers support it with HTML: underline.

For example, in LLM responses, bold is great for highlighting key points like enhance readability.medium.com
